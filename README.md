# Micro Rush — GPverse

Versione 2026 del classico per PC *Micro Machines*: corse in miniatura viste dall'alto sul tavolo di casa.
Gioco in un unico file HTML, senza dipendenze, che gira nel browser su PC e telefono.

## Come giocare

Apri `index.html` in un browser moderno.

- **Gara**: giri contro 3 avversari guidati dall'IA.
- **Eliminazione**: la telecamera segue chi è in testa; chi esce dallo schermo è fuori dal round. Vince chi arriva a 5 round.

Comandi: P1 frecce, P2 W A S D, gamepad, touch. Pausa con P o Esc.
